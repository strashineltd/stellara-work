# Stellara Work · Calm Workspace

## Intent

以用户提供的参考图为视觉基准，把 Stellara Work 设计成清楚、安静、可信的 Windows 桌面工作台。界面重点是本地项目、工作记录和任务输入，不做营销落地页，也不模仿常见的深色 AI 聊天产品。

## Product boundary

- 产品是本地优先的个人工作台，核心对象为项目、会话、任务、本地文件、模型和设置。
- 不开发登录、注册、账号、头像、个人中心或团队成员体系。
- 参考图中的用户头像、通知和团队入口不照搬，替换为本地文件、工作区和设置能力。
- 保留现有 Electron IPC、数据持久化、审批和任务执行语义。
- 默认不创建项目、会话或全局工作目录；模型连接与本地项目相互独立。
- 每个项目由用户显式选择或新建的入口文件建立，文件父目录成为该项目的工作区；程序配置与数据库使用系统标准应用数据目录。

## Visual language

- 应用使用 Windows hidden title bar overlay，内容直接延伸到窗口最顶部；不显示原生黑色标题条、应用图标或标题文字，但保留系统最小化、最大化和关闭按钮。
- 主强调色使用干净的品牌蓝 `#2F7CF4`；选中态使用极浅蓝 `#EEF4FF`，主文字近黑 `#111827`。
- 只用细边框、低对比表面和宽而淡的蓝灰阴影建立层级；禁止霓虹、发光、渐变、玻璃、网格与装饰噪点。
- 最外层应用壳为 0px 圆角并紧贴客户区四边；信息卡 14–16px，常规控件 9–12px。圆角只用于内部功能分组，不使用夸张胶囊和卡片套卡片。
- 使用仓库现有 `assets/icon-256.png` 作为品牌标记；功能图标统一为 16px、1.5px 描边 SVG，不使用 emoji。

## Typography

- UI：Segoe UI Variable / Segoe UI / PingFang SC / Microsoft YaHei UI。
- 路径与代码：Cascadia Code / Consolas。
- 正文 13–14px，说明 12px，导航 13px；首页标题 24–28px，卡片标题 13–14px。
- 字重控制在 400–700；不用超大营销标题、全大写英文标签或装饰字体。

## Layout

- 主应用壳以 100% 宽高铺满沉浸式窗口客户区，四周不留外边距、外框或悬浮阴影，并裁切内部滚动。
- 顶栏高度约 72px：空白区域承担系统拖拽与双击最大化；按钮、链接、表单和菜单为 no-drag；右上角依据 Window Controls Overlay safe area 动态避让原生 caption buttons。
- 左侧导航宽 206–220px：一级导航为首页、项目、工作记录、文件、设置；其下保留可搜索的项目与会话树。
- 首页主内容沿中心轴布局（任务台）：标题行（命令式口吻，不使用客套问候）→ 宽任务提交区 → 任务模板 → 「继续工作」横带。
- 项目页复用同一内容区展示项目网格；工作记录页承载现有标签、连续任务流、输入器和可选检查器。
- 首次启动欢迎页为独立向导：欢迎介绍 → 选模型 → 连接详情 → 选工作目录；重新配置模型时跳过欢迎与选目录两步。
- 920px 以下侧栏与检查器转为覆盖层；首页逐步收窄，页面不得横向溢出。

## Components

- 一级导航选中态：浅蓝底、品牌蓝图标与文字，圆角 10–12px，不能只依靠颜色表达。
- 任务提交区：白色表面、明确 1px 边框、轻阴影、右下角「交给 Agent」文字按钮；保持 aria-label、键盘提交和禁用状态。
- 任务模板：轻边框按钮，hover 只改变边框、底色和 1–2px 位移，不缩放。
- 「继续工作」横带：无卡片容器，只有紧凑行条目与分隔线；行条目 hover 改变底色，不缩放。
- 信息卡：白色、细边框、14–16px 圆角；标题、内容列表、底部动作形成固定三段层次。仅项目页使用，首页不使用信息卡。
- 工作区检查器：作为全局右侧面板，在首页、项目和工作记录中都由同一个按钮状态控制；按钮状态与面板真实可见性必须一致，并使用 `aria-controls` 建立关联。
- 项目创建窗口：点击侧栏或项目页的“新建项目”后打开 520px 左右的紧凑 dialog；窗口顶部是必填项目名称，下方以两个并列轻边框动作为“选择文件 / 新建文件”，入口文件同样必选，结果路径使用等宽字体并提供显式打开操作，底部以“取消 / 创建项目”完成提交。关闭或取消不得提前生成占位项目。
- 已有项目主体点击只展开/收起关联会话；项目更多菜单中的“编辑项目”可复用同一窗口的编辑模式，用于重命名和文件管理，避免普通点击与创建入口语义混淆。
- 设置窗口维持固定外框尺寸，tab 切换只动画内容的 opacity/translate，禁止动画 width/height。

## Interaction

- hover 120–160ms，页面与浮层进入 180–240ms，统一使用 ease-out；只动画 opacity、transform、颜色与阴影。
- 所有按钮必须有可见文字或 aria-label；键盘焦点使用 2px 品牌蓝外环。
- 删除项目和会话继续保留确认、等待状态与就地错误反馈。
- 项目创建窗口打开后聚焦名称字段，支持 Escape、取消与明确关闭按钮；最终创建期间禁用关闭和重复提交，失败后保留用户输入并在名称区域使用 alert 宣布。异步文件动作期间相关按钮禁用，选择/创建成功使用 status 宣布。
- `prefers-reduced-motion` 下关闭非必要动画。

## Dark theme

- 深色作为用户可选主题继续保留，但不作为产品默认视觉。
- 使用冷调深蓝灰表面，不用纯黑、霓虹和高亮发光；信息层级仍由边框和表面明度表达。
