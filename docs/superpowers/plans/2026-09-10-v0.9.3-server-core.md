# Stellara Work 0.9.3 服务器连接 — 主进程内核实施计划（Plan 2A/2B）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 opencode 兼容服务端的连接内核：服务器配置与凭据、HTTP/SSE 客户端、事件与消息适配、会话与聊天桥接（IPC dispatch），全部可用单测验证。

**Architecture:** 主进程新增 `electron/server/` 模块：`types.ts`（宽容解析的远端类型）、`opencode-client.ts`（fetch + eventsource-parser，Basic 鉴权）、`event-adapter.ts`（SSE 事件 → 现有 `ChatStreamEvent`，含文本增量与工具状态映射）、`message-adapter.ts`（远端消息 → 现有 `MessageRow[]`）、`server-manager.ts`（配置 CRUD + 连接状态 + 事件订阅分发）、`session-bridge.ts`（sessions:* 的本地/服务器分派）。渲染层完全不改（Plan 2B 接入）。

**Tech Stack:** Electron 主进程 TypeScript + Node fetch + `eventsource-parser`（现有依赖）+ better-sqlite3（现有）+ Vitest（node 环境）。

**Spec:** `docs/superpowers/specs/2026-09-10-v0.9.3-redesign-server-scheduler-design.md`（第 4 节、6 节 IPC 中 servers 部分、7 节迁移）

## Global Constraints

- 凭据永不回传渲染层：IPC 只暴露 `hasPassword: boolean`；测试不得断言或打印密码。
- URL 仅允许 `http` / `https`（拒绝 `file:` 等）；无尾斜杠存储。
- 本计划不新增 npm 依赖（复用 `eventsource-parser`）。
- 服务器会话消息不落本地库；本地映射行只存元数据（title/时间/runtime/server_id/remote_session_id）。
- 现有本地会话行为不变：sessions/chat 的本地路径保持原逻辑。
- 类型严格（`npm run typecheck` 通过）；全量 `npm test` 在每个任务提交前保持绿色。
- 远端字段宽容解析：`unknown` 输入 + 运行时窄化，缺字段不崩溃。
- 中文文案与现有代码风格一致；无注释除非文件已有。

  const map = await readEnv();
  map.set(serverKeyName(serverId), encodeStored(password));
  await writeEnv(map);
}
