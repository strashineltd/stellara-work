# Stellara Work 0.9.3 已安排调度器 + 托盘驻留 实施计划（Plan 3/3）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现「已安排」完整调度器（一次性 / 间隔 / Cron、托盘驻留、启动错过补偿）与发布收尾。

**Architecture:** 主进程 `electron/scheduler/`：croner 计算下次运行，单一最小堆计时器触发；本地任务以「无 UI 会话」复用现有 Agent 循环（危险工具默认拒绝——C1 失败关闭语义），服务器任务走 opencode 桥接；SQLite 持久化任务与执行记录；托盘负责驻留与菜单；渲染层新增「已安排」页面与设置开关。

**Tech Stack:** Electron 主进程 + better-sqlite3 + croner（新增唯一依赖）+ React 19 + Vitest。

**Spec:** `docs/superpowers/specs/2026-09-10-v0.9.3-redesign-server-scheduler-design.md` §5/§6.3/§12（版本发布）
**相关既定约束（安全修复后）:** 危险工具在无审批回调时失败关闭（`46b4d50`）；会话按身份隔离（H10）；服务器凭据/URL 规则（H9）。

## Global Constraints

- 新增依赖仅 `croner`；类型严格（`noUnusedLocals`）；全量 `npm test` 每任务保持绿色。
- 调度任务归属本地身份（`user_id`）：仅运行/展示当前身份的任务；切换身份后调度器重载该身份的任务集。
- **安全**：调度触发为「无交互会话」——不传 `onApproval`，危险工具按既有失败关闭语义被拒绝（不写文件、不执行命令）；每任务可选 `allowDangerous`（默认 false，UI 明示风险），开启后仍禁止 `run_command` 网络类命令（沿用结构白名单）。
- 服务器任务：仅使用已连接服务器；断线时运行标记 `error`（不静默重排）。
- 托盘驻留：关闭窗口隐藏；`Cmd+Q`/托盘退出真正退出；设置 `app.backgroundScheduling` 默认 true（false 时保持现状：关窗即退）。
- 执行记录只保留最近 N=200 条/任务（防无限增长）。

### Task 2: 调度引擎（croner + 单计时器 + 错过补偿）

**Files:**
- Create: `electron/scheduler/engine.ts`
- Test: `electron/scheduler/engine.test.ts`

**Interfaces:**
- Produces:
  - `computeNextRun(kind: 'once'|'interval'|'cron', expr: string, from: Date): Date | null`（`croner` 封装；`once` 解析 ISO；`interval` 分钟数）
  - `class SchedulerEngine { constructor(deps: { listDue(now): Task[]; onFire(task): Promise<void>; now?(): Date; setTimer; clearTimer }) start(): void; stop(): void; reschedule(): void }`——单计时器 + 最小堆；到点调用 `onFire`（异常捕获记日志不中断）。
  - `computeMissed(tasks, now): Task[]`（`enabled && next_run_at < now`；同一任务多条错过只补跑一次）
  - 错过补偿：启动时对每个 missed 任务补写一条 `missed` 记录、执行一次补跑（结果照常记 success/error）、重算 `next_run_at`。

- [ ] **Step 2: 运行 → FAIL。**（如 `croner` 未装先 `npm install croner`）
- [ ] **Step 3: 实现**（croner 支持 `Cron` 与 interval；一次性用 ISO 解析）。
